## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/DHANUSH-916/Personal-Portfolio.git
```

### Navigate to the Backend

```bash
cd server
```

### Install Dependencies

```bash
npm install
```

### Create a `.env` File

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Start the Backend

```bash
npm start
```

### Run the Frontend

Open:

```text
client/index.html
```

or run it using **Live Server** in Visual Studio Code.
